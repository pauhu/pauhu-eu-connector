# Pauhu connector entries

This repository is for anyone who uses the European Language Data Space and wants to read what Pauhu Ltd offers there. It holds the dataset entries and usage policies Pauhu Ltd publishes in its connector. Start with `entries.json`.

## Files

- `entries.json`: the dataset entries, in LanguageDCAT-AP 0.9.5.
- `policies.json`: the usage policies attached to the entries, in ODRL.

## Requests

Open an issue with the Request form. One request per issue: name the entry or policy, what should change, and why.
