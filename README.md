# Pauhu connector entries

Dataset entries and usage policies that Pauhu Ltd publishes in the European Language Data Space connector.

## What will be here

- entries.json: the dataset entries (LanguageDCAT-AP 0.9.5).
- policies.json: the usage policies attached to the entries.
- validation/: the SHACL validation report for each export.

Files are added only after each export has passed validation. Every new file is shared here before it is imported.

## Requests

Open an issue with the Request form. One request per issue: name the entry or policy, what should change, and why.
